# SVD experiment inputs

Place images you are legally entitled to process in `files/` (for example,
`files/0/front_img.jpg`). Start `svd.py` from this directory to run the
interactive singular-value experiment; processed output appears in `files_SVD/`.

Photographic samples from the academic research dataset are not distributed here.
Create these directories locally when needed. Do not include acquired photographs
or generated outputs when publishing the source. The backend's SVD endpoint accepts
PNG data from authenticated users and keeps runtime results in private storage.
